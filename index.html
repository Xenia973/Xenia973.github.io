Event Organizer App

This is a work in progress. The Event Organizer app/website is meant to help people find and/or host events in their neighborhood. This app will ask for the user's preferences on what kind of event they are looking for, their party size, what location they prefer and other such information to help narrow down their search. The project will mostly consist of HTML and CSS. I hope to be able to add interactive elements to the website, so that it can actually function. I believe JavaScript is the best way to add interactivity, though we could perhaps use Python.
